# AutoFilterBot

A Python Telegram auto-filter bot that searches connected channels and returns matching files to users.

## Features
- Channel-based file search
- Document, video, and media filtering
- Group/channel management commands
- MongoDB integration
- Docker and Heroku deployment support

## Setup
```bash
git clone https://github.com/AmanNishad20/AutoFilterBot.git
cd AutoFilterBot
pip install -r requirements.txt
python3 main.py
```

Configure the required Telegram API, bot, authorization, and database values before running.
